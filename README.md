Open and run the notebooks from this directory. Keep the `lib` folder beside them.

```bash
python -m pip install -r lib/requirements.txt
```

```bash
python -m pip install torch torchvision
```

Complete the `# FILL` sections, replace `...` expressions, and fill in the written-answer cells. Remove the corresponding `NotImplementedError` when implementing a function. Run cells in order after completing the required code. Supplied test and plotting cells use your implementations.
